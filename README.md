# MolCom

웹캠을 실시간으로 감시하다가 블랙리스트에 등록해 둔 사람이 화면에 잡히면,
미리 지정해 둔 창으로 즉시 포커스를 전환하는 Windows용 프로그램이다.

## 설치와 실행

[Releases](https://github.com/ehgns-k/CNSA-MolCom/releases/latest)에서
`MolCom.exe`를 내려받아 실행한다. 설치 과정은 없으며 Python도 필요 없다.
64비트 Windows 10 이상에서 동작한다.

서명되지 않은 실행 파일이므로 처음 실행할 때 Windows SmartScreen 경고가
나올 수 있다. "추가 정보"를 누른 뒤 "실행"을 선택한다.

## 사용법

1. "블랙리스트"에서 "사진으로 등록..."을 눌러 감지할 사람의 얼굴 사진을 고르고
   이름을 입력한다. 정면에 가까운 사진 1장이면 등록된다.
2. "전환할 창"에서 대상 창을 고른다. 목록에 없으면 "목록 새로 고침"을 누른다.
3. "전환 테스트"로 창이 제대로 전환되는지 확인한다.
4. "감시 시작"을 누른다.

## 동작 방식

1. 웹캠 프레임마다 얼굴을 검출한다 (OpenCV YuNet 모델).
2. 얼굴마다 특징 벡터를 구해 블랙리스트와 대조한다 (OpenCV SFace 모델).
3. 등록된 사람이 있으면 지정한 창을 전면으로 가져온다. 최소화되어 있으면 복원한다.
4. 등록된 사람이 화면에 있는 동안에는 매 프레임 이 동작을 반복한다.
   사용자가 다른 창으로 돌아가도 곧바로 다시 전환되며, 해제 조작은 없다.

등록되지 않은 사람은 몇 명이 보이든 전환하지 않는다.

영상은 저장하거나 전송하지 않으며, 모든 처리는 PC 안에서 이루어진다.
등록한 사진도 보관하지 않고 얼굴 특징 벡터만 저장한다.

## 설정

| 설정 | 설명 |
| --- | --- |
| 카메라 번호 | 기본 웹캠은 0이다. 카메라가 여러 대면 1, 2, ... 를 시도한다. |
| 검출 신뢰도 기준 | 얼굴 검출 기준. 낮출수록 민감해진다. 기본값 70. |
| 연속 감지 프레임 수 | 1이면 감지 즉시 전환한다. 오인식이 잦으면 2~3으로 올린다. |
| 인물 일치 기준 | 낮출수록 쉽게 같은 사람으로 본다. 기본값 36은 OpenCV 권장값(0.363)이다. |

인식이 잘 안 되면 "사진 추가..."로 같은 사람의 다른 각도, 다른 조명 사진을
더 등록한다. 다른 사람을 등록된 사람으로 잘못 인식하면 인물 일치 기준을 올린다.

설정은 `%APPDATA%\MolCom\settings.json`, 블랙리스트는
`%APPDATA%\MolCom\blacklist.json`에 저장된다.

## 제한 사항

- 얼굴로 사람을 식별하므로, 카메라를 등지고 있거나 얼굴이 가려진 경우,
  얼굴이 너무 작게 잡히는 경우에는 인식되지 않는다.
- 대상 창은 창 핸들로 기억한다. 창을 닫았다가 다시 열면 제목이 같은 창을
  찾으며, 찾지 못하면 다시 선택해야 한다.
- 관리자 권한으로 실행 중인 창으로 전환하려면 MolCom도 관리자 권한으로
  실행해야 할 수 있다.

## 직접 빌드

Python 3.9 이상이 설치된 Windows에서 `build.bat`을 실행하면
`dist\MolCom.exe`가 만들어진다. 릴리스의 실행 파일은 `v`로 시작하는 태그를
푸시할 때 GitHub Actions(`.github/workflows/build.yml`)가 같은 스크립트로 빌드한다.

빌드 없이 소스에서 실행하려면 다음과 같이 한다.

```bat
python -m pip install -r requirements.txt
pythonw main.pyw
```

테스트는 `python -m unittest discover -s tests`로 실행한다.

## 라이선스 관련

[OpenCV Zoo](https://github.com/opencv/opencv_zoo)에서 가져온 것이며
각각 MIT, Apache 2.0 라이선스로 배포된다.
