# MolCom

카메라를 실시간으로 감시하다가 블랙리스트에 등록해 둔 사람이 화면에 잡히면,
미리 지정해 둔 창(Windows) 또는 앱(Android)으로 즉시 전환하는 프로그램이다.

## 내려받기

[Releases](https://github.com/ehgns-k/CNSA-MolCom/releases/latest)에서 받는다.

| 플랫폼 | 파일 | 요구 사항 |
| --- | --- | --- |
| Windows | `MolCom.exe` | 64비트 Windows 10 이상. 설치 과정과 Python이 필요 없다. |
| Android | `MolCom.apk` | Android 8.0 이상, ARM 기기. |

- Windows: 서명되지 않은 실행 파일이므로 처음 실행할 때 SmartScreen 경고가
  나올 수 있다. "추가 정보"를 누른 뒤 "실행"을 선택한다.
- Android: Play 스토어 밖의 앱이므로 설치할 때 "출처를 알 수 없는 앱 설치"를
  허용해야 한다.

iOS는 지원하지 않는다. iOS는 앱이 화면에 없을 때 카메라를 쓰거나 다른 앱을
앞으로 가져오는 것을 허용하지 않는다.

## 사용법

두 플랫폼 모두 화면 맨 위의 상태 표시가 다음에 할 일을 알려 준다.

1. **감지할 사람 등록** - 카메라로 바로 찍거나 사진 파일을 고른 뒤 이름을
   입력한다. 정면에 가까운 사진 1장이면 등록된다. 같은 이름으로 다시 등록하면
   그 사람의 사진이 추가되어 인식이 좋아진다.
2. **전환할 대상 선택** - Windows에서는 열려 있는 창, Android에서는 설치된 앱을
   고른다. "전환 테스트"로 미리 확인할 수 있다.
3. **감시 시작**을 누른다.

### Windows

- 감시 중에 창을 닫으면 알림 영역(트레이)으로 들어가 계속 실행된다.
  트레이 아이콘을 두 번 누르면 창이 다시 열리고, 오른쪽 단추 메뉴에서
  감시를 멈추거나 프로그램을 끝낼 수 있다.
- MolCom 창을 직접 조작하는 동안에는 창을 전환하지 않는다. 등록된 사람이
  계속 화면에 있어도 감시를 멈추거나 설정을 바꿀 수 있게 하기 위함이다.
- [옵션]에서 카메라 번호, 인식 민감도, 감지 즉시 전환 여부, 시작 시 자동 감시를
  바꿀 수 있다.

### Android

- 처음 감시를 시작할 때 카메라 권한과 "다른 앱 위에 표시" 권한을 요청한다.
  뒤의 권한은 MolCom이 화면에 없을 때 다른 앱을 앞으로 가져오는 데 필요하다.
- 감시 중에는 알림이 계속 표시되며, 알림의 "감시 중지"로 멈출 수 있다.
- 전면 카메라를 쓴다. 기기를 세로로 세워 둔 상태를 기준으로 얼굴을 찾는다.

## 동작 방식

1. 카메라 프레임마다 얼굴을 검출한다 (OpenCV YuNet 모델).
2. 얼굴마다 특징 벡터를 구해 블랙리스트와 대조한다 (OpenCV SFace 모델).
3. 등록된 사람이 있으면 지정한 창 또는 앱을 전면으로 가져온다.
4. 등록된 사람이 화면에 있는 동안에는 이 동작을 계속 반복한다. Windows는
   매 프레임, Android는 1초마다 반복한다. 다른 창으로 돌아가도 곧바로 다시
   전환되며, 해제 조작은 없다.

등록되지 않은 사람은 몇 명이 보이든 전환하지 않는다.

영상은 저장하거나 전송하지 않으며, 모든 처리는 기기 안에서 이루어진다.
등록한 사진도 보관하지 않고 얼굴 특징 벡터만 저장한다. 저장 위치는
Windows에서는 `%APPDATA%\MolCom`, Android에서는 앱 내부 저장소이다.

## 인식 민감도

| 값 | 일치 기준 | 쓰는 경우 |
| --- | --- | --- |
| 낮음 | 0.45 | 다른 사람을 등록된 사람으로 잘못 인식할 때 |
| 보통 | 0.363 | 기본값. OpenCV가 SFace 모델에 권장하는 값 |
| 높음 | 0.30 | 등록된 사람을 놓칠 때 |

## 제한 사항

- 얼굴로 사람을 식별하므로, 카메라를 등지고 있거나 얼굴이 가려진 경우,
  얼굴이 너무 작게 잡히는 경우에는 인식되지 않는다.
- Windows: 대상 창은 창 핸들로 기억한다. 창을 닫았다가 다시 열면 제목이 같은
  창을 찾으며, 찾지 못하면 다시 선택해야 한다. 관리자 권한으로 실행 중인
  창으로 전환하려면 MolCom도 관리자 권한으로 실행해야 할 수 있다.
- Android: 제조사의 배터리 절약 기능이 백그라운드 앱을 종료하면 감시가 멈춘다.
  이 경우 기기 설정에서 MolCom을 배터리 최적화 대상에서 제외한다.

## 직접 빌드

`main`에 푸시하면 GitHub Actions(`.github/workflows/build.yml`)가 두 플랫폼을
빌드해 `molcom/__init__.py`의 버전에 해당하는 릴리스에 올린다.

- Windows: Python 3.9 이상이 설치된 Windows에서 `build.bat`을 실행하면
  `dist\MolCom.exe`가 만들어진다. 빌드 없이 실행하려면
  `python -m pip install -r requirements.txt` 후 `pythonw main.pyw`를 실행한다.
- Android: JDK 17, Android SDK, Gradle 8.7이 있는 환경에서
  `gradle -p android assembleRelease`를 실행한다. 얼굴 모델은 `models/` 폴더의
  파일을 그대로 쓴다. APK는 저장소의 `android/molcom.keystore`로 서명한다.
  이 키는 공개되어 있으므로 배포자를 증명하는 용도로는 쓸 수 없다.

테스트는 `python -m unittest discover -s tests`로 실행한다.

## 라이선스 관련

`models/` 폴더의 YuNet, SFace 모델은
[OpenCV Zoo](https://github.com/opencv/opencv_zoo)에서 가져온 것이며
각각 MIT, Apache 2.0 라이선스로 배포된다.
