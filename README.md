# MolCom

웹캠을 실시간으로 감시하다가 주 사용자 외에 다른 사람이 화면에 잡히면,
미리 지정해 둔 창으로 즉시 포커스를 전환하는 Windows용 프로그램이다.

## 동작 방식

1. 웹캠 프레임마다 얼굴을 검출한다 (OpenCV YuNet 모델).
2. 얼굴이 2개 이상이면 추가 인물이 있는 것으로 판단한다.
3. 지정한 창을 전면으로 가져온다. 최소화되어 있으면 복원한다.
4. 추가 인물이 사라지고 "재감시 대기 시간"이 지나면 다시 감시한다.
   그 전까지는 사용자가 원래 창으로 돌아가도 다시 전환하지 않는다.

영상은 저장하거나 전송하지 않으며, 모든 처리는 PC 안에서 이루어진다.

## 실행

Python 3.9 이상이 필요하다.

```bat
python -m pip install -r requirements.txt
pythonw main.pyw
```

단일 실행 파일이 필요하면 `build.bat`을 실행한다. `dist\MolCom.exe`가 만들어진다.

## 사용법

1. "전환할 창"에서 대상 창을 고른다. 목록에 없으면 "목록 새로 고침"을 누른다.
2. "전환 테스트"로 창이 제대로 전환되는지 확인한다.
3. "감시 시작"을 누른다.

| 설정 | 설명 |
| --- | --- |
| 카메라 번호 | 기본 웹캠은 0이다. 카메라가 여러 대면 1, 2, ... 를 시도한다. |
| 검출 신뢰도 기준 | 낮출수록 민감해지고 오검출이 늘어난다. 기본값 70. |
| 연속 감지 프레임 수 | 1이면 감지 즉시 전환한다. 오검출이 잦으면 2~3으로 올린다. |
| 재감시 대기 시간 | 추가 인물이 사라진 뒤 다시 감시를 시작하기까지의 시간(초). |

설정은 `%APPDATA%\MolCom\settings.json`에 저장된다.

## 제한 사항

- 얼굴을 기준으로 사람을 세므로, 카메라를 등지고 있거나 얼굴이 가려진 사람은
  감지되지 않는다.
- 미리 보기에서 가장 큰 얼굴(녹색)을 주 사용자로 표시하지만, 전환 판정은
  얼굴 수만으로 한다. 주 사용자가 자리를 비운 상태에서 한 사람만 나타나면
  전환되지 않는다.
- 대상 창은 창 핸들로 기억한다. 창을 닫았다가 다시 열면 제목이 같은 창을
  찾으며, 찾지 못하면 다시 선택해야 한다.
- 관리자 권한으로 실행 중인 창으로 전환하려면 MolCom도 관리자 권한으로
  실행해야 할 수 있다.
